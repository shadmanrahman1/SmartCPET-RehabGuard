🐛 TROUBLESHOOTING:
   
   Problem: "Disconnected" status
   Solution:
   1. Check Pi server running: python3 pi_server.py
   2. Verify Pi IP: hostname -I
   3. Test: curl http://192.168.1.101:5000
   4. Same WiFi network

   Problem: No waveform
   Solution:
   1. Check Arduino: ls /dev/ttyUSB*
   2. Verify data: cat /dev/ttyUSB0
   3. Check Pi server logs
